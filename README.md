# EfficientCalc

A lightweight and fast calculator written in modern C++.

## Features (v0.1.0)

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Exponentiation (^)
* Square Root (r)
* Percentage (%)

## Requirements

* A C++ compiler with C++11 support or newer.
* Windows.

## Build

Compile the project:

```bash
g++ calculadora.cpp -o EfficientCalc
```

Run the executable:

```bash
./EfficientCalc
```
